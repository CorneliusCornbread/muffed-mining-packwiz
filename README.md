# Muffed Mining

This is the packwiz repository for the eTards **Muffed Mining** modpack. 

Not much to put here other than the `migrate-modpack.sh` script is capable of using the `modlist.md` file to import a markdown list of mods. Particularly useful if you're using Prism and want to switch to packwiz.

DO NOTE HOWEVER, the migration script does not preserve versions despite it reading them in via the markdown. You may find you run into version issues upon migration.
